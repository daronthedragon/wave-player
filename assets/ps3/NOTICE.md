# PS3 interface texture provenance

These PNG files are unmodified PS3 interface assets obtained from the public
TheGammaSqueeze/xmb-web reference project on 2026-10-14:
https://github.com/TheGammaSqueeze/xmb-web

- `xmb_icon_001.png`: Settings toolbox (`icons/xmb_icon_001.png` upstream).
- `xmb_icon_003.png`: Music category (`icons/xmb_icon_003.png`).
- `xmb_icon_004.png`: Video category (`icons/xmb_icon_004.png`).
- `xmb_icon_037.png`: Playlists (`icons/xmb_icon_037.png`).
- `xmb_icon_008.png`: Update arrows, used for compatibility conversion (`icons/xmb_icon_008.png`).
- `icon_fw_track.png`: Default music file (`images/icon_fw_track.png`).
- `icon_fw_folder.png`: Music folder (`images/icon_fw_folder.png`).
